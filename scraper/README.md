# Budgy — עדכון משכנתא חודשי

מביא את **יתרת הקרן** ואת **פירוט המסלולים** ממזרחי טפחות אל Supabase,
מעדכן את הדוח החודשי ב-Budgy, ושולח התראת פוש:

> **המשכנתא ירדה ב-2,674 ₪**
> יתרה: 827,934 ₪ · 0.32%- מהחודש שעבר · 3 מסלולים

העדכון נעשה **מהמחשב** פעם בחודש, בסקריפט Playwright. יש גם בוקמרקלט
לאייפון — הוא כתוב ובנוי אבל **עוד לא עבד** מול הבנק (ראה בהמשך).

---

## למה זה לא אוטומטי לגמרי

לבנקים בישראל אין API ציבורי, ויש OTP והגנת אנטי-בוט. בנוסף, Budgy לא יכול
לקרוא נתונים מאתר הבנק — ה-same-origin policy של הדפדפן חוסם את זה, וזה
בדיוק מה שמונע מכל אתר אקראי לגנוב נתוני בנק.

לכן **אתה** מתחבר (סיסמה + OTP), ורק אחרי שאתה בפנים הקוד רץ. הוא לא מקליד,
לא קורא ולא שומר פרטי הזדהות.

## הזרימה החודשית

1. **ב-15 בחודש** מגיע פוש: "צריך לעדכן את יתרת המשכנתא".
   (`pg_cron` → `budgy_mortgage_reminder`, נשלח רק אם עוד לא נקלט snapshot החודש.)
2. **בכניסה ל-Budgy** מופיע באנר עם אותה תזכורת וכפתור שפותח את הבנק.
   הבאנר מופיע מה-12 בחודש ונעלם ברגע שהעדכון נקלט.
3. **במחשב**: `node scraper/mortgage-recorder.mjs` — נפתח דפדפן, אתה מתחבר,
   נכנס למסך המשכנתא, והשאר אוטומטי.
4. הפוש מגיע עם ההפרש, והבאנר נעלם.

## הבוקמרקלט לאייפון — לא עובד עדיין

בניסיון הראשון ה-`fetch` ל-`/Online/api/mashkanta/profile` הצליח והחזיר JSON
תקין, אבל **בלי השדה `mashkantaot`** — כלומר הבנק החזיר משהו אחר מהתגובה
שנקלטה ב-`--discover`. כנראה ה-endpoint דורש קונטקסט או header שה-SPA שולח.

האבחון שופר: הבוקמרקלט מדפיס עכשיו אילו שדות כן חזרו. כדי להמשיך לחקור,
פתח בספארי (מחובר) את `mto.mizrahi-tefahot.co.il/Online/api/mashkanta/profile`
וראה מה מוצג.

### בנייה (במחשב)

```bash
node scraper/build-bookmarklet.mjs
```

נוצר `scraper/bookmarklet.txt`. שלח את התוכן שלו לעצמך — מייל, וואטסאפ
לעצמך, או Notes המסונכרן.

> הקובץ מכיל סוד ולכן ב-`.gitignore`. **הרפו ציבורי** — אל תדביק את התוכן
> שלו לשום קובץ בפרויקט.

### באייפון

1. פתח **ספארי** על אתר כלשהו.
2. לחץ **שיתוף** (החץ למעלה) ← **הוסף סימנייה**.
3. תן לה את השם `עדכון משכנתא`, שמור במיקום **מועדפים**, ולחץ **שמור**.
4. לחץ על אייקון **הסימניות** (הספר) ← **עריכה** ← לחץ על `עדכון משכנתא`.
5. מחק את שורת הכתובת, **הדבק** את הקוד שקיבלת, ולחץ **סיום**.

בדיקה: היכנס לבנק, התחבר, לך למסך המשכנתא, ולחץ על הסימנייה. אמורה לקפוץ
הודעה ירוקה למטה עם הסכום.

## איפה יושב מה

```
אייפון:  ספארי → בוקמרקלט ──┐ x-budgy-secret
                            ├──► record-mortgage ──► mortgage_snapshots
מחשב:    run.bat → Playwright ┘ x-push-secret        monthly_records
                                 (service_role)      send-push
```

**לאף אחד מהלקוחות אין מפתח DB.** לכל אחד סוד משלו שיודע לרשום snapshot של
משכנתא ותו לא, ו-`service_role` נשאר בתוך ה-Edge Function. גם הפירסור נמצא
רק שם, כך ששינוי שדה בבנק מתוקן ב-redeploy — בלי להתקין מחדש סימנייה בטלפון.

## אם הבוקמרקלט נכשל

ההודעה האדומה אומרת מה קרה:

| הודעה | מה לעשות |
|---|---|
| `הרץ את זה מתוך האתר של מזרחי טפחות` | אתה לא על דומיין הבנק |
| `הבנק החזיר 401 / 403` | הסשן פג — התחבר מחדש ונסה שוב |
| `התגובה מהבנק לא נראתה כמו מסך משכנתא` | הבנק שינה מבנה — הרץ `--discover` במחשב ושלח לי את הקובץ |

`--discover` שומר את כל התגובות ל-`discovery/<timestamp>/`. `_index.json` הוא
רשימת ה-endpoints. הקבצים מכילים נתוני חשבון אמיתיים והם ב-`.gitignore`.

## מה נשמר

**`mortgage_snapshots`** — שורה לחודש: `balance` (יתרת קרן),
`payoff_balance`, `early_repayment_fees`, `routes` (שם/יתרה/ריבית/הצמדה/
החזר/תאריך סיום/תיק), `confidence`, `source`, ו-`raw` — ה-JSON המקורי.

`raw` נשמר בכוונה: אם הבנק ישנה מבנה בעוד חצי שנה, אפשר לפרסר מחדש היסטוריה
קיימת במקום לאבד חודשים.

**`monthly_records`** — אם כבר קיים דוח לחודש הנוכחי, ה-`mortgage_balance`
שלו מתעדכן וכרטיסיית המשכנתא ב-Budgy מציגה את המספר החדש. הקוד **לא** יוצר
דוח חדש — דוח ריק היה נראה באפליקציה כאילו אין לך נכסים בכלל.

## איך זה נראה ב-Budgy

לחיצה על כרטיסיית **יתרת משכנתא** במסך הדוח פותחת פירוט מלא:

- **יתרת קרן** כמספר הראשי, ולצידה יתרה לסילוק והריבית הצבורה שביניהן
- **ריבית משוקללת**, **החזר חודשי**, **עמלת פירעון מוקדם**, וכמה זמן נותר
- **תמהיל** — בר שמראה את החלוקה בין קבועה/פריים/משתנה, וסימון אם יש הצמדה למדד
- **כרטיס לכל מסלול** — יתרה, אחוז מהיתרה, ריבית, הצמדה, החזר ותאריך סיום
- **תיקי המשכנתא** — סכום מקורי מול יתרה לכל תיק בנפרד

הצבע מסמן את סוג הריבית (ירוק=קבועה, כתום=פריים, כחול=משתנה) והוא עקבי בין
הבר, ה-pills והכרטיסים. הסכום המקורי מוצג לכל תיק בנפרד ולא כסך הכל — מיחזור
מופיע כתיק שני שנלקח מהראשון, וחיבור שלהם היה מנפח את המספר.

עד שנקלט snapshot ראשון, הלחיצה מציגה את גרף ההיסטוריה כמו קודם.
